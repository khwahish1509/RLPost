# LoCoMo public-benchmark runs

Dataset: `locomo10.json` from snap-research/locomo (public). Download:
curl -sL https://raw.githubusercontent.com/snap-research/locomo/main/data/locomo10.json -o benchmarks/locomo/locomo10.json

Harness: `scripts/bench_locomo.py`. Arms: trained / untrained / empty.
Results (receipts: every notebook + answer) live in `results/<arm>/`.
